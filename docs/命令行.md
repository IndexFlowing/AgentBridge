# 命令行

CLI 是 AgentBridge 的第一控制面，完整的管理能力均可在无 GUI 环境使用。默认启动级配置来自 `~/.agentbridge/config.toml`。

```bash
agentbridge --version
agentbridge --help
```

## 命令总览

| 命令 | 作用 |
| --- | --- |
| `serve` | 前台启动 MCP Server + Web 控制平面（唯一底层入口） |
| `start` | 后台启动服务 |
| `stop` | 停止后台服务 |
| `restart` | 重启后台服务（stop + start） |
| `status` | 查看服务生命周期状态 |
| `workspace` | 查看默认工作区状态 |
| `doctor` | 检查运行依赖与环境 |
| `skill ...` | 管理 Agent 根、规则与技能 |
| `task ...` | 任务生命周期 |

## serve（前台）

```bash
agentbridge serve
agentbridge serve --host 127.0.0.1 --port 8040
agentbridge serve --allow-any-host          # 通过隧道访问时放开 Host 校验
agentbridge serve --dev                     # 本机调试，关闭 /mcp 401 挑战（等价 --no-auth）
agentbridge serve --auth-token "$TOKEN"     # 额外静态 Bearer Token
agentbridge serve --admin-password "$PIN"   # 固定 OAuth 授权页 PIN
agentbridge serve --client-id ... --client-secret ...
```

`serve` 读取 `~/.agentbridge/config.toml`；CLI 参数与 `AGENTBRIDGE_*` 环境变量作为内存覆盖。启动横幅会打印监听地址与（未固定时的）Admin PIN。

## 服务生命周期

```bash
agentbridge start                 # 后台启动；已在运行时不会重复启动
agentbridge status                # running/stopped、PID、监听地址
agentbridge stop                  # 停止记录在案的 PID
agentbridge stop --force          # 健康检查无法确认归属时强制停止
agentbridge restart               # 等价 stop + start
agentbridge restart --force
```

`start` 以分离进程方式调用 `serve`，把服务 PID 与监听地址写入 `~/.agentbridge/service.json`；stdout/stderr 写入 `~/.agentbridge/service.log`。生命周期状态**不依赖 SQLite**。

## workspace 与 doctor

```bash
agentbridge workspace   # 当前默认项目、类型、git 状态、任务状态
agentbridge doctor      # config / workspace / port / bind / auth / opencode / git / cloudflared
```

## skill

```bash
agentbridge skill list
agentbridge skill show <name>
agentbridge skill install <source> [--name <name>]
agentbridge skill enable <name>
agentbridge skill disable <name>
agentbridge skill remove <name>
agentbridge skill agent [--project <name>]
agentbridge skill rule <name> [--project <name>]
```

`<source>` 支持本地目录、`http(s)://` 归档与 `github:user/repo`。详见 [Agent体系](Agent体系.md)。

## task

```bash
# 启动（--execute 会前台启动 Executor 并等待；缺省只写入 PLAN）
agentbridge task start --goal "..." --tests "cargo test" [--executor <name>] [--execute]

# 查看 / 取消
agentbridge task status
agentbridge task cancel [--task-id <id>]

# 手动回填结果
agentbridge task executed --status success|failure|blocked \
  [--task-id <id>] [--iteration N] [--tests "..."] [--exit-code 0] \
  [--changed-files "a,b"] [--summary "..."]
```

`task` 默认作用于第一个/默认项目。C2C 语义见 [C2C协议](C2C协议.md)。

## 配置与环境变量

- 字段优先级：`CLI 参数 > AGENTBRIDGE_* 环境变量 > ~/.agentbridge/config.toml`。
- 仅认证相关字段支持环境变量（`AGENTBRIDGE_AUTH_TOKEN`、`AGENTBRIDGE_ADMIN_PASSWORD`、`AGENTBRIDGE_CLIENT_ID`、`AGENTBRIDGE_CLIENT_SECRET`、`AGENTBRIDGE_NO_AUTH` 等）。
- 监听地址/端口来自 `CLI 参数 > config.toml`，不依赖 SQLite；修改后需 `agentbridge restart`（后台）或重启 `serve`（前台）。

完整配置参考见 [配置](配置.md)。
