# 配置

AgentBridge 的配置分为两类，职责严格区分：

- **启动级配置**：`config.toml`（host / port / 认证 / 日志 / executor / proxy / security）——唯一 Source of Truth，不依赖 SQLite。
- **运行数据 / 动态管理数据**：SQLite `~/.agentbridge/agentbridge.db`（项目、执行器、任务、OAuth、Provider、Proxy、Skill）。

## 配置文件位置与优先级

| 位置 | 说明 |
| --- | --- |
| `--config <path>` | 显式指定，优先级最高 |
| `./.agentbridge.toml` | 项目级配置 |
| `~/.agentbridge/config.toml` | 用户级配置（`serve` / `start` 使用；首次启动自动创建） |
| `/etc/agentbridge/config.toml` | 系统级配置（仅 Unix） |

字段优先级：`CLI 参数 > AGENTBRIDGE_* 环境变量 > config.toml`。仅认证相关字段支持环境变量。

## config.toml 参考

```toml
workspace = "/absolute/path/to/project"   # 必填；默认项目工作区

host = "127.0.0.1"                         # 默认 127.0.0.1
port = 8040                                # 见下方端口说明
allow_any_host = true                      # 是否放开 MCP Host 校验（隧道场景）
auth_token = ""                            # 静态 Bearer Token，空表示不启用
admin_password = ""                        # OAuth 授权页 PIN，空表示启动时随机生成
client_id = ""                             # 静态 OAuth 客户端
client_secret = ""
no_auth = false                            # 关闭 /mcp 401 挑战（仅供本机）
tunnel_token = ""                          # 命名隧道 token
tunnel_hostname = ""

[executor]
type = "opencode"                          # 默认执行器类型
command = "opencode"                       # 可执行命令
mode = "stream"                            # stream | silent

[proxy]
enabled = false                            # 全局代理兜底
kind = "http"                              # http | https | socks5
host = ""
port = 0
username = ""
password = ""

[security]
max_file_size = 1048576                    # 1 MiB
deny_sensitive_files = true
max_diff_bytes = 65536

[logging]
level = "info"                             # RUST_LOG 优先级更高
```

> 端口说明：**调试构建默认 `8040`，发布 / 安装构建默认 `8030`**（`cargo install` / `cargo build --release`）。显式配置 `port` 可覆盖。

> 相对路径的 `workspace` 会相对 `config.toml` 所在目录解析并转为绝对路径。

## 环境变量

| 变量 | 作用 |
| --- | --- |
| `AGENTBRIDGE_AUTH_TOKEN` | 静态 Bearer Token |
| `AGENTBRIDGE_ADMIN_PASSWORD` | OAuth 授权页 PIN |
| `AGENTBRIDGE_CLIENT_ID` / `AGENTBRIDGE_CLIENT_SECRET` | 静态 OAuth 客户端 |
| `AGENTBRIDGE_NO_AUTH` | `1`/`true`/`yes` 时关闭 401 挑战 |
| `RUST_LOG` | 覆盖日志级别 |

## 修改生效方式

- 修改 `config.toml` 后需重启：
  - 后台服务：`agentbridge restart`
  - 前台进程：重启 `agentbridge serve`
- host / port 不写入 SQLite。

## UI 偏好

`~/.agentbridge/ui.toml` 保存 Web 端偏好（`auto_start`、`start_tunnel`）。这是提示性配置，不是启动级 Source of Truth。

## 数据目录

```text
~/.agentbridge/config.toml            # 启动级配置
~/.agentbridge/agentbridge.db         # 运行数据（项目/执行器/任务/OAuth/Provider/Proxy/Skill）
~/.agentbridge/credentials.key        # Provider 凭据 AES 密钥（Unix 0600）
~/.agentbridge/.agent/                # Agent 配置根（Agent.yaml / Rules / Skills / projects）
~/.agentbridge/handoff/<task_id>.c2c  # 单次任务的渲染交接副本（非权威）
~/.agentbridge/service.json           # 后台服务 PID / 监听地址
~/.agentbridge/service.log            # 后台服务 stdout/stderr
~/.agentbridge/ui.toml                # Web 端偏好
<workspace>/.agentbridge/state.json   # 工作区内运行状态
<workspace>/.agentbridge/executor.pid # 运行中的 Executor 进程号（与 service.json 无关）
```
